## 📁 Typical Project Structure

Each application is organized independently:

```text

│
├── index.html

└── process.php
```

Some projects may contain additional files depending on their requirements.

### File Responsibilities

**`index.html`**

Contains the user interface and input form.

Contains the visual design, layout, colors, and responsive styling.

**`process.php`**

Processes the submitted information and generates the result dynamically.

## ▶️ How to Run the Projects

These projects can be run using a local PHP server such as **XAMPP**.

### 1. Install XAMPP

Install XAMPP and start:

```text
Apache
```

### 2. Place the Project Folder

Copy the project folder into:

```text
C:\xampp\htdocs\
```

For example:

```text
C:\xampp\htdocs\php-tasks\
```

### 3. Open in Browser

Start Apache and open:

```text
http://localhost/php-tasks/
```

Open the required project's `index.html`.
